# Построение локальной двухточечной CAN-сети: передача угла поворота вала и тока с узла привода на управляющий узел

**Продолжительность:** 4 академических часа

**Целевая аудитория:** Студенты 3–4 курсов 

**Аппаратная база:** Два микроконтроллерных узла на базе К1921ВГ01Т (RISC-V) / трансиверы SN65HVD230 / шина CAN 2.0B

## 1\. Цель работы

- Изучить физический, канальный и прикладной уровни промышленной шины **CAN 2.0B** (Controller Area Network) в робототехнических комплексах.
- Освоить расчет таймингов битового интервала (кванты времени $t_q$, фазовые сегменты `PROP_SEG`, `PHASE_SEG1`, `PHASE_SEG2`, точка стробирования `Sample Point`).
- Настроить аппаратные почтовые ящики (Mailboxes/FIFO) и маски фильтрации идентификаторов (Filter ID / Mask) контроллера CAN микроконтроллера К1921ВГ01Т.
- Организовать распределенный обмен данными между двумя узлами:
	- **Узел 1 (Slave / Привод):** сбор показаний угла с энкодера и тока фазы с АЦП, упаковка в структуру CAN-кадра данных и циклическая передача с частотой 100 Гц.
		- **Узел 2 (Master / Контроллер верхнего уровня):** прием пакета по прерыванию, валидация, распаковка физических величин и отправка встречных управляющих уставок.

## 2\. Теоретические сведения

### 2.1. Физический уровень и арбитраж шины CAN

Шина CAN использует дифференциальную линию передачи данных: две сигнальные линии **CAN\_H** и **CAN\_L**.

```
Рецессивное состояние (бит '1')        Доминантное состояние (бит '0')
CAN_H:                       2.5 В                                    3.5 В
CAN_L:                       2.5 В                                    1.5 В
Дифференциал (Vdiff):         0 В                                     2.0 В

```

- **Терминация:** на обоих концах физической линии устанавливаются согласующие резисторы $120\text{ Ом}$ (суммарное сопротивление линии между CAN\_H и CAN\_L равно $60\text{ Ом}$) для предотвращения отражения электромагнитных волн.
- **Неразрушающий побитовый арбитраж:** доминантный уровень (лог. `0`) подавляет рецессивный уровень (лог. `1`). Если два узла начинают передачу одновременно, узел с меньшим числовым значением идентификатора (`CAN ID`) выигрывает арбитраж без задержки и коллизии на линии.

### 2.2. Расчет структуры битового интервала (Bit Timing)

Номинальное битовое время $T_{bit}$ делится на четыре неперекрывающихся сегмента, состоящих из целочисленного количества элементарных квантов времени $t_q$ (Time Quanta):

```
|<--------------------------------- 1 Номинальный бит ---------------------------------->|
+-----------+-----------------------+-----------------------+----------------------------+
| SYNC_SEG  |       PROP_SEG        |      PHASE_SEG1       |         PHASE_SEG2         |
|  (1 tq)   |       (1..8 tq)       |       (1..8 tq)       |         (1..8 tq)          |
+-----------+-----------------------+-----------------------+----------------------------+
                                                            ^
                                                    Точка выборки (Sample Point)
```
1. **SYNC\_SEG (1 $t_q$):** сегмент синхронизации фронтов сигналов.
2. **PROP\_SEG:** компенсация задержек распространения сигнала в физическом кабеле и трансиверах.
3. **PHASE\_SEG1 и PHASE\_SEG2:** фазовые компенсаторы фазового сдвига.
4. **Sample Point (Точка выборки):** момент стробирования уровня линии. Для надежной работы в робототехнике и автомобильных стандартах точка стробирования выбирается в диапазоне **75% – 87.5%** от начала бита:

$$
\mathrm{Sample Point} = \frac{\mathrm{SYNC\_SEG} + \mathrm{PROP\_SEG} + \mathrm{PHASE\_SEG1}}{\mathrm{Total } t_q} \cdot 100\%
$$

### 2.3. Структура стандартного кадра данных (Data Frame 2.0B)

Стандартный кадр использует 11-битный идентификатор (Base ID):

- **SOF (1 бит):** Start of Frame (доминантный ноль).
- **Identifier (11 бит):** приоритет и адрес сообщения.
- **RTR (1 бит):** Remote Transmission Request (0 для кадра данных).
- **IDE (1 бит):** Identifier Extension (0 для стандартного 11-битного формата).
- **DLC (4 бита):** Data Length Code (количество байт полезной нагрузки, $0 \dots 8$).
- **Data Field (0..8 байт):** полезные данные.
- **CRC (15 бит + 1 бит Delimiter):** контрольная сумма кадра.
- **ACK (1 бит + 1 бит Delimiter):** подтверждение приема любым узлом сети.
- **EOF (7 бит):** End of Frame (рецессивные единицы).

## 3\. Расчетные формулы для настройки контроллера CAN

### 1\. Расчет битовой скорости

При частоте шины периферии $F_{CANCLK} = 100\text{ МГц}$ и требуемой битовой скорости $F_{bit} = 500\text{ кбит/с}$ ($T_{bit} = 2.0\text{ мкс}$):

$$
\text{Total } t_q = \frac{T_{bit}}{t_q} = \frac{F_{CANCLK}}{\text{BRP} \cdot F_{bit}}
$$

Выберем предделитель $\text{BRP} = 10 \implies F_{tq} = \frac{100\text{ МГц}}{10} = 10\text{ МГц}$ ($t_q = 100\text{ нс}$).

Тогда суммарное число квантов на бит:

$$
\text{Total } t_q = \frac{2000\text{ нс}}{100\text{ нс}} = 20\text{ } t_q
$$

### 2\. Распределение квантов по сегментам (Sample Point = 80%)

- $\text{SYNC\_SEG} = 1\text{ } t_q$ (фиксировано стандартом)
- $\text{PROP\_SEG} = 5\text{ } t_q$
- $\text{PHASE\_SEG1} = 10\text{ } t_q$
- $\text{PHASE\_SEG2} = 4\text{ } t_q$
- $\text{SJW (Synchronization Jump Width)} = 2\text{ } t_q$

Проверка точки стробирования:

$$
\text{Sample Point} = \frac{1 + 5 + 10}{20} \cdot 100\% = \frac{16}{20} \cdot 100\% = 80.0\% \quad (\text{соответствует стандарту CiA})
$$

## 4\. Спецификация сообщений разрабатываемой сети

Сеть состоит из двух узлов с предопределенными идентификаторами кадра:

| ID кадра (StdId) | Направление               | Длина (DLC) | Поле данных (Байты 0..7)                                                                                                               | Описание параметров                       |
| ---------------- | ------------------------- | ----------- | -------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------- |
| **`0x320`**      | Узел привода   →   Мастер | 8 байт      | `[0..3]`:   θshaft​   (int32, отсчеты) `[4..5]`:   Iphase​   (int16, мА)      `[6]`: Статус (uint8)<br>`[7]`: Счетчик Alive (uint8)    | Телеметрия привода (период 10 мс, 100 Гц) |
| **`0x321`**      | Мастер   →  Узел привода  | 6 байт      | `[0..1]`: Целевая скорость (int16, об/мин)<br>`[2]`: Режим управления (uint8)<br>`[3]`: Флаг включения ШИМ (uint8)<br>`[4..5]`: Резерв | Команды управления (по событию / 50 Гц)   |
| **`0x010`**      | Мастер   →   Все узлы     | 1 байт      | `[0]`: Причина останова                                                                                                                | Аварийный останов (Emergency Stop)        |

## 5\. Оборудование и инструменты

1. Два отладочных модуля с микроконтроллерами **К1921ВГ01Т** (RISC-V).
2. Два 3.3V CAN-трансивера (SN65HVD230 или аналогичные).
3. Витая пара проводов длиной 0.5–1.0 м с установленными согласующими резисторами $120\text{ Ом}$ на обоих концах.

## 7\. Пример исходного кода программы

### 7.1. Модуль инициализации CAN и фильтрации (`can_driver.c`)

```c
#include "k1921vg01t.h"
#include <stdint.h>
#include <stdbool.h>
#include <string.h>

#define CAN_MSG_TELEMETRY_ID   0x320
#define CAN_MSG_COMMAND_ID     0x321

// Структура кадра телеметрии привода (8 байт)
typedef struct __attribute__((packed)) {
    int32_t  shaft_angle_ticks; // Угол вала с энкодера
    int16_t  phase_current_ma;  // Ток фазы в мА
    uint8_t  drive_status;      // 0 = Стоп, 1 = Работа, 2 = Авария
    uint8_t  alive_counter;     // Инкрементный счетчик пакетов
} can_telemetry_pkt_t;

/**
 * @brief Инициализация блока CAN0 на скорость 500 кбит/с (100 МГц тактовая)
 */
void CAN0_Bitrate_500k_Init(void)
{
    // 1. Тактирование блока CAN0 и снятие сброса
    RCU->HCLKCFG_bit.CAN0EN = 1;
    RCU->HRSTCFG_bit.CAN0EN = 1;

    // 2. Вход в режим конфигурации (Reset Mode)
    CAN0->MOD_bit.RM = 1;

    // 3. Настройка таймингов: BRP = 10 (/10), PROP+PHASE1 = 15, PHASE2 = 4, SJW = 2
    // BTR0: [7..6] SJW-1, [5..0] BRP-1
    CAN0->BTR0 = ((2 - 1) << 6) | (10 - 1);
    
    // BTR1: [7] SAM (0 = 1 точка), [6..4] TSEG2-1, [3..0] TSEG1-1 (TSEG1 = PROP + PHASE1)
    CAN0->BTR1 = (0 << 7) | ((4 - 1) << 4) | ((15 - 1) << 0);

    // 4. Настройка аппаратного фильтра в одиночном режиме (Single Filter Mode)
    CAN0->MOD_bit.AFM = 1; 

    // Выход из режима конфигурации (запуск контроллера)
    CAN0->MOD_bit.RM = 0;
}

/**
 * @brief Настройка фильтра на прием конкретного ID (например, 0x320)
 */
void CAN0_Set_RxFilter(uint16_t filter_id, uint16_t mask)
{
    CAN0->MOD_bit.RM = 1; // Переход в режим настройки

    // Запись 11-битного ID в регистры Acceptance Code (ACR)
    CAN0->ACR[0] = (uint8_t)(filter_id >> 3);
    CAN0->ACR[1] = (uint8_t)((filter_id & 0x07) << 5);

    // Запись маски Acceptance Mask (AMR): 0 - проверка бита, 1 - игнорирование
    CAN0->AMR[0] = (uint8_t)(mask >> 3);
    CAN0->AMR[1] = (uint8_t)((mask & 0x07) << 5) | 0x1F;

    CAN0->MOD_bit.RM = 0; // Запуск
}

/**
 * @brief Отправка кадра телеметрии привода (Узел 1)
 */
bool CAN0_Send_Telemetry(int32_t angle, int16_t current, uint8_t status)
{
    static uint8_t counter = 0;
    can_telemetry_pkt_t pkt;

    pkt.shaft_angle_ticks = angle;
    pkt.phase_current_ma  = current;
    pkt.drive_status      = status;
    pkt.alive_counter     = counter++;

    // Проверка готовности буфера передачи (TBS = Transmit Buffer Status)
    if (!CAN0->SR_bit.TBS) {
        return false; // Буфер занят отправкой
    }

    // Запись идентификатора 0x320 (Std ID) и DLC = 8
    CAN0->TX_BUF[0] = (uint8_t)(CAN_MSG_TELEMETRY_ID >> 3);
    CAN0->TX_BUF[1] = (uint8_t)((CAN_MSG_TELEMETRY_ID & 0x07) << 5); // RTR = 0
    CAN0->TX_BUF[2] = 8; // DLC = 8 байт

    // Копирование 8 байт полезной нагрузки
    memcpy((void*)&CAN0->TX_BUF[3], &pkt, 8);

    // Команда на передачу (Transmission Request)
    CAN0->CMR_bit.TR = 1;
    return true;
}
```

### 7.2. Обработчик прерывания приема кадра на Узле 2 (Мастер)


```c
volatile int32_t master_received_angle = 0;
volatile int16_t master_received_current = 0;
volatile uint8_t master_received_alive = 0;

/**
 * @brief Обработчик прерывания контроллера CAN0
 */
void CAN0_IRQHandler(void)
{
    // Проверка флага прерывания по приему (Receive Interrupt)
    if (CAN0->IR_bit.RI) 
    {
        // Чтение принятого ID
        uint16_t id = ((uint16_t)CAN0->RX_BUF[0] << 3) | (CAN0->RX_BUF[1] >> 5);
        uint8_t dlc = CAN0->RX_BUF[2] & 0x0F;

        if (id == CAN_MSG_TELEMETRY_ID && dlc == 8) 
        {
            can_telemetry_pkt_t recv_pkt;
            memcpy(&recv_pkt, (void*)&CAN0->RX_BUF[3], 8);

            master_received_angle   = recv_pkt.shaft_angle_ticks;
            master_received_current = recv_pkt.phase_current_ma;
            master_received_alive   = recv_pkt.alive_counter;
        }

        // Освобождение буфера приема (Release Receive Buffer)
        CAN0->CMR_bit.RRB = 1;
    }
}
```

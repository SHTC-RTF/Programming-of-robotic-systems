## 2\. Теоретические сведения

### 2.1. Особенности протокола SPI для инерциальных датчиков

Интерфейс SPI датчиков движения серии MPU-9250/6500 поддерживает частоту тактирования до 1 МГц при конфигурировании регистров и до 20 МГц при пакетном чтении данных.

```
Байт 0               Байт 1               Байт 2               ...  Байт 14
MOSI: [0x3B | 0x80] -----> [0x00] ------------> [0x00] ------------> ... [0x00]
            (Чтение с ACCEL_XOUT_H)
MISO: [Не значащий] -----> [ACCEL_X_H] -------> [ACCEL_X_L] -------> ... [GYRO_Z_L]
```
- **Флаг чтения (Read bit):** Старший бит передаваемого байта адреса устанавливается в `1` (`0x80 | RegAddr`). Если старший бит равен `0`, датчик воспринимает операцию как запись.
- **Пакетное чтение (Burst Read):** При удержании линии `CS = 0` внутренний указатель адреса датчика инкрементируется автоматически. Это позволяет за одну транзакцию вычитать 14 последовательных байт:
	- `ACCEL_XOUT [H:L]`, `ACCEL_YOUT [H:L]`, `ACCEL_ZOUT [H:L]` (6 байт)
		- `TEMP_OUT [H:L]` (2 байта)
		- `GYRO_XOUT [H:L]`, `GYRO_YOUT [H:L]`, `GYRO_ZOUT [H:L]` (6 байт)

### 2.2. Зачем нужен DMA при опросе IMU

В алгоритмах ориентации и балансировки частота опроса IMU составляет от 200 Гц до 1 кГц. Программное ожидание каждого байта по флагам FIFO SPI («пока освободится буфер») приводит к потерям тысяч процессорных тактов.

**Схема работы через DMA:**

1. Аппаратный таймер с периодом $T_s = 5\text{ мс}$ (200 Гц) инициирует транзакцию.
2. Контроллер DMA выставляет линию `CS = 0` и прокачивает 15 байт: передает буфер `spi_tx_buf` (адрес регистра + нули) и одновременно складывает принятые байты в буфер ОЗУ `imu_raw_rx_buf`.
3. По завершении DMA генерирует прерывание, выставляет `CS = 1`, а ядро RISC-V за десяток микросекунд производит математический расчет ориентации.

### 2.3. Математика комплементарного фильтра

Акселерометр и гироскоп обладают взаимно дополняющими спектральными недостатками:

- **Акселерометр:** измеряет вектор кажущегося ускорения (включая силу тяжести $\vec{g}$). Точен на низких частотах (в статике), но крайне чувствителен к вибрациям привода и линейным ускорениям робота.
	AHRS - Read the Docs
- **Гироскоп:** измеряет угловую скорость $\vec{\omega}$. Высокая точность в динамике (высокие частоты), но прямое интегрирование накапливает ошибку из-за смещения нуля (дрейф гироскопа / Bias Drift).

#### 1\. Оценка углов по акселерометру

В состоянии покоя вектор гравитации позволяет однозначно определить углы крена ($\phi_{acc}$) и тангажа ($\theta_{acc}$):

AHRS - Read the Docs

$$
\phi_{acc} = \text{atan2}(a_y, a_z) \cdot \frac{180^\circ}{\pi}
$$

$$
\theta_{acc} = \text{atan2}\left(-a_x, \sqrt{a_y^2 + a_z^2}\right) \cdot \frac{180^\circ}{\pi}
$$

#### 2\. Интегрирование гироскопа

$$
\phi_{gyro}[k] = \phi[k-1] + \omega_x \cdot \Delta t
$$

$$
\theta_{gyro}[k] = \theta[k-1] + \omega_y \cdot \Delta t
$$

#### 3\. Уравнение слияния (Complementary Fusion)

AHRS - Read the Docs

Комбинация фильтра низких частот (ФНЧ для акселерометра) и фильтра высоких частот (ФВЧ для гироскопа):

$$
\theta[k] = \alpha \cdot \left(\theta[k-1] + \omega_y \cdot \Delta t\right) + (1 - \alpha) \cdot \theta_{acc}[k]
$$

$$
\phi[k] = \alpha \cdot \left(\phi[k-1] + \omega_x \cdot \Delta t\right) + (1 - \alpha) \cdot \phi_{acc}[k]
$$

Коэффициент $\alpha$ связывает квант времени $\Delta t$ и постоянную времени фильтра $\tau$:

$$
\alpha = \frac{\tau}{\tau + \Delta t}, \quad \tau \approx 0.5\text{--}1.0\text{ с} \implies \alpha \in [0.95 \dots 0.99]
$$

## 3\. Расчетные соотношения и масштабирование

1. **Масштабирование сырых отсчетов:** Датчик возвращает 16-разрядные знаковые числа со знаком (`int16_t` в дополнительном коде).
	- При диапазоне акселерометра $\pm 4g$: чувствительность $S_{acc} = 8192\text{ LSB/}g$.
		$$
		a_x = \frac{\text{raw\_acc\_x}}{8192.0} \quad [g]
		$$
		- При диапазоне гироскопа $\pm 1000^\circ/\text{с}$: чувствительность $S_{gyro} = 32.8\text{ LSB/}(^\circ/\text{с})$.
		$$
		\omega_x = \frac{\text{raw\_gyro\_x} - \text{bias}_x}{32.8} \quad [^\circ/\text{с}]
		$$
2. **Калибровка смещения нуля гироскопа ($\text{bias}$):** При неподвижном датчике усредняются $N = 1000$ отсчетов:
	$$
	\text{bias}_x = \frac{1}{N} \sum_{i=1}^N \text{raw\_gyro\_x}[i]
	$$

## 6\. Пример программной реализации

### 6.1. Инициализация SPI и считывание регистров


```c
#include "k1921vg01t.h"
#include <stdint.h>
#include <stdbool.h>
#include <math.h>

#define MPU_READ_FLAG       0x80
#define REG_WHO_AM_I        0x75
#define REG_PWR_MGMT_1      0x6B
#define REG_ACCEL_CONFIG    0x1C
#define REG_GYRO_CONFIG     0x1B
#define REG_ACCEL_XOUT_H    0x3B

#define SPI_CS_PIN_MASK     (1 << 3) // Порт A, Пин 3 (Программный CS)

static inline void IMU_CS_Low(void)  { GPIOA->DATAOUTCLR = SPI_CS_PIN_MASK; }
static inline void IMU_CS_High(void) { GPIOA->DATAOUTSET = SPI_CS_PIN_MASK; }

uint8_t SPI0_TransferByte(uint8_t tx_data)
{
    while (SPI0->SR_bit.TNF == 0); // Ожидание места в буфере TX
    SPI0->DR = tx_data;
    while (SPI0->SR_bit.RNE == 0); // Ожидание приема байта
    return (uint8_t)(SPI0->DR);
}

void IMU_WriteReg(uint8_t reg, uint8_t data)
{
    IMU_CS_Low();
    SPI0_TransferByte(reg & ~MPU_READ_FLAG);
    SPI0_TransferByte(data);
    IMU_CS_High();
}

uint8_t IMU_ReadReg(uint8_t reg)
{
    uint8_t val;
    IMU_CS_Low();
    SPI0_TransferByte(reg | MPU_READ_FLAG);
    val = SPI0_TransferByte(0x00);
    IMU_CS_High();
    return val;
}
```

### 6.2. Настройка пакетного обмена через DMA и обработка отсчетов


```c
#define BURST_LEN 15 // 1 байт адреса + 14 байт данных (6 Accel, 2 Temp, 6 Gyro)

static uint8_t imu_tx_buf[BURST_LEN] __attribute__((aligned(4)));
static uint8_t imu_rx_buf[BURST_LEN] __attribute__((aligned(4)));

typedef struct {
    float roll;
    float pitch;
    float gyro_bias_x;
    float gyro_bias_y;
    float alpha;
    float dt;
} imu_filter_t;

static imu_filter_t imu_state;

void IMU_DMA_Config(void)
{
    // Буфер передачи: первый байт — начальный адрес регистра чтения, остальные нули
    imu_tx_buf[0] = REG_ACCEL_XOUT_H | MPU_READ_FLAG;
    for (int i = 1; i < BURST_LEN; i++) imu_tx_buf[i] = 0x00;

    // Конфигурация канала DMA TX (ОЗУ -> SPI0 DR)
    DMA->CH[1].SRC = (uint32_t)&imu_tx_buf[0];
    DMA->CH[1].DST = (uint32_t)&(SPI0->DR);
    DMA->CH[1].CTRL_bit.SRCSZ = 0;  // 8 бит
    DMA->CH[1].CTRL_bit.DSTSZ = 0;
    DMA->CH[1].CTRL_bit.SRCINC = 1; // Инкремент буфера ОЗУ
    DMA->CH[1].CTRL_bit.DSTINC = 3; // Фиксированный адрес SPI DR
    DMA->CH[1].CTRL_bit.TOTAL = BURST_LEN - 1;

    // Конфигурация канала DMA RX (SPI0 DR -> ОЗУ)
    DMA->CH[2].SRC = (uint32_t)&(SPI0->DR);
    DMA->CH[2].DST = (uint32_t)&imu_rx_buf[0];
    DMA->CH[2].CTRL_bit.SRCSZ = 0;
    DMA->CH[2].CTRL_bit.DSTSZ = 0;
    DMA->CH[2].CTRL_bit.SRCINC = 3; // Фиксированный адрес SPI DR
    DMA->CH[2].CTRL_bit.DSTINC = 1; // Инкремент буфера ОЗУ
    DMA->CH[2].CTRL_bit.TOTAL = BURST_LEN - 1;

    // Разрешение прерывания по окончанию приема
    DMA->CH[2].INTEN_bit.TC = 1;
    PLIC_EnableIRQ(DMA2_IRQn);
}

// Запуск сеанса чтения (вызывается таймером каждые 5 мс)
void IMU_Trigger_Read(void)
{
    IMU_CS_Low();
    // Активация каналов DMA
    DMA->CH[1].EN_bit.ENABLE = 1;
    DMA->CH[2].EN_bit.ENABLE = 1;
}

// Прерывание завершения передачи DMA RX
void DMA2_IRQHandler(void)
{
    if (DMA->CH[2].STATUS_bit.TC) 
    {
        IMU_CS_High(); // Закрываем транзакцию SPI
        DMA->CH[2].STATUSCLR_bit.TC = 1;

        // Распаковка сырых данных (Big-Endian в датчике)
        int16_t raw_ax = (int16_t)((imu_rx_buf[1]  << 8) | imu_rx_buf[2]);
        int16_t raw_ay = (int16_t)((imu_rx_buf[3]  << 8) | imu_rx_buf[4]);
        int16_t raw_az = (int16_t)((imu_rx_buf[5]  << 8) | imu_rx_buf[6]);

        int16_t raw_gx = (int16_t)((imu_rx_buf[9]  << 8) | imu_rx_buf[10]);
        int16_t raw_gy = (int16_t)((imu_rx_buf[11] << 8) | imu_rx_buf[12]);
        int16_t raw_gz = (int16_t)((imu_rx_buf[13] << 8) | imu_rx_buf[14]);

        // Перевод в физические величины
        float ax = (float)raw_ax / 8192.0f; // Диапазон +-4g
        float ay = (float)raw_ay / 8192.0f;
        float az = (float)raw_az / 8192.0f;

        float gx = ((float)raw_gx - imu_state.gyro_bias_x) / 32.8f; // Диапазон +-1000 dps
        float gy = ((float)raw_gy - imu_state.gyro_bias_y) / 32.8f;

        // 1. Оценка углов по акселерометру
        float roll_acc  = atan2f(ay, az) * 57.29578f;
        float pitch_acc = atan2f(-ax, sqrtf(ay * ay + az * az)) * 57.29578f;

        // 2. Комплементарная фильтрация
        imu_state.roll  = imu_state.alpha * (imu_state.roll  + gx * imu_state.dt) + 
                          (1.0f - imu_state.alpha) * roll_acc;

        imu_state.pitch = imu_state.alpha * (imu_state.pitch + gy * imu_state.dt) + 
                          (1.0f - imu_state.alpha) * pitch_acc;
    }
}
```

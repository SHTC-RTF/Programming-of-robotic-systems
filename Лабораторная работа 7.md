# Дискретный ПИД-регулятор скорости DC-мотора с защитой от интегрального насыщения (Anti-Windup) и цифровой фильтрацией дифференциальной составляющей

**Продолжительность:** 4–6 академических часов

**Целевая аудитория:** Студенты 3–4 курсов 
**Аппаратная платформа:** Микроконтроллер К1921ВГ01Т (RISC-V) / STM32F4 (ARM Cortex-M4), стендовый DC-мотор с квадратурным энкодером и H-мостом

## 1\. Цель работы

- Освоить практические методы синтеза и дискретизации ПИД-регуляторов для задач точного слежения и стабилизации скорости электропривода.
- Изучить природу эффекта интегрального насыщения (**Integrator Windup**) в нелинейных системах с ограничением выходного сигнала и реализовать алгоритм активного зажима (**Anti-Windup Clamping**).
- Исследовать проблему высокочастотного шума квантования при дифференцировании сигналов обратной связи энкодера и реализовать дифференцирование по выходу (**Derivative on Measurement**) с рекурсивным фильтром низкой частоты (ФНЧ 1-го порядка).
- Выполнить экспериментальную параметрическую настройку регулятора на стенде и оценить показатели качества управления (время переходного процесса, статическая ошибка, перерегулирование).

## 2\. Теоретические сведения

### 2.1. Структура реального промышленного цифрового ПИД-регулятора

Классический учебный ПИД-регулятор $u(t) = K_p e(t) + K_i \int e(t)dt + K_d \frac{de(t)}{dt}$ в микроконтроллерных системах управления приводами в исходном виде неприменим из-за двух физических ограничений:

```
Уставка W_ref [+]         Ошибка e[k]       +-------------+
------------------->( Σ ) ----------------> |  П-канал    | ----+
                      ^ [-]                 +-------------+     |
                      |                                         |
                      |                     +-------------+     |  U_unsat  +--------------+  U[k]
                      |                     |  И-канал    | ----+---------> | Ограничитель |-----> ШИМ
                      |                     | (Clamping)  |     |           |  [-100, 100] |
                      |                     +-------------+     |           +--------------+
                      |                                         |
                      |   -W_meas           +-------------+     |
                      +-------------------> |  Д-канал    | ----+
                             (d/dt)         |  (ФНЧ LPF)  |
                                            +-------------+
```
1. **Ограничение мощности силового ключа:** Скважность ШИМ ограничена пределами $D \in [-100\%, +100\%]$ (или $[-U_{max}, +U_{max}]$).
2. **Дискретность энкодера:** Измерение скорости $\omega_{meas}[k]$ содержит шумы квантования $\pm 1$ импульс. Прямая разность ошибки $(e[k] - e[k-1])$ приводит к колоссальным броскам выходного напряжения.

### 2.2. Защита от интегрального насыщения (Anti-Windup Clamping)

Если двигатель не может разогнаться до заданной скорости из-за нехватки напряжения питания или механического момента, ошибка $e[k] = \omega_{ref} - \omega_{meas}$ остается положительной. Интегратор продолжает накапливать сумму $I[k] = I[k-1] + K_i T_s e[k]$, уходя в огромные значения.

Когда уставка сбрасывается в 0, двигатель **продолжает вращаться на максимальной скорости**, пока накопленный интеграл медленно разряжается обратной ошибкой.

**Алгоритм условного интегрирования (Clamping):** Интегрирование замораживается ($I[k] = I[k-1]$), если выполняются одновременно два условия:

- Суммарный ненасыщенный выход регулятора вышел за пределы ($U_{unsat} \ge U_{max}$ или $U_{unsat} \le U_{min}$).
- Знак текущей ошибки $e[k]$ совпадает со знаком переполнения (ошибка усугубляет насыщение).

### 2.3. Модификация дифференциального канала

- **Дифференцирование по скорости (Derivative on Measurement):** Производная берется от измеренного сигнала скорости, а не от ошибки:
	$$
	\frac{de(t)}{dt} = \frac{d(\omega_{ref} - \omega_{meas})}{dt} \xrightarrow{\omega_{ref} = \text{const}} -\frac{d\omega_{meas}}{dt}
	$$
	Это устраняет «дифференциальный удар» (скачок в насыщение) при ступенчатом изменении уставки оператором.
- **Фильтрация производной ФНЧ 1-го порядка:** Для подавления шумов квантования сигнал пропускается через экспоненциальный фильтр с постоянной времени $\tau_f$:
	$$
	D[k] = \beta \cdot D[k-1] - (1 - \beta) \cdot \frac{K_d}{T_s} \cdot (\omega_{meas}[k] - \omega_{meas}[k-1]), \quad \beta = \frac{\tau_f}{\tau_f + T_s}
	$$
	*Рекомендация:* постоянную времени фильтра выбирают в диапазоне $\tau_f \in [2 \cdot T_s \dots 5 \cdot T_s]$.

## 3\. Расчетные формулы

1. **Разностные уравнения регулятора на шаге $k$ ($T_s$ — период дискретизации):**
	- Ошибка: $e[k] = \omega_{ref}[k] - \omega_{meas}[k]$
		- П-составляющая: $P[k] = K_p \cdot e[k]$
		- Д-составляющая: $D[k] = \beta \cdot D[k-1] - (1 - \beta) \cdot \frac{K_d}{T_s} \cdot (\omega_{meas}[k] - \omega_{meas}[k-1])$
		- Предварительный выход: $U_{pre}[k] = P[k] + D[k]$
		- Проверка зажима интегратора:
		$$
		\Delta I[k] = \begin{cases} 0, & \text{если } (U_{pre} + I[k-1] \ge U_{max}) \land (e[k] > 0) \\ 0, & \text{если } (U_{pre} + I[k-1] \le U_{min}) \land (e[k] < 0) \\ K_i \cdot T_s \cdot e[k], & \text{иначе} \end{cases}
		$$
		- Интеграл: $I[k] = I[k-1] + \Delta I[k]$
		- Итоговый ограниченный выход: $U[k] = \text{clip}(U_{pre}[k] + I[k], \, U_{min}, \, U_{max})$

## 6\. Пример программной реализации модуля регулятора

### 6.1. Заголовочный файл `pid_regulator.h`

```c
#ifndef PID_REGULATOR_H
#define PID_REGULATOR_H

#include <stdint.h>
#include <stdbool.h>

typedef struct {
    // Настроечные коэффициенты
    float Kp;
    float Ki;
    float Kd;
    float Ts;              // Период вызова дискретного контура (секунды)

    // Параметры насыщения
    float out_max;
    float out_min;

    // Внутренние переменные состояния
    float integral;
    float prev_meas;
    float prev_d_term;
    float beta;            // Коэффициент ФНЧ дифференциатора
    bool anti_windup_en;   // Флаг включения защиты Anti-Windup
} pid_controller_t;

void PID_Init(pid_controller_t *pid, float kp, float ki, float kd, float ts, 
              float out_min, float out_max, float tau_filter, bool enable_aw);
void PID_Reset(pid_controller_t *pid);
float PID_Compute(pid_controller_t *pid, float setpoint, float measurement);

#endif // PID_REGULATOR_H
```

### 6.2. Исходный код `pid_regulator.c`

```c
#include "pid_regulator.h"

void PID_Init(pid_controller_t *pid, float kp, float ki, float kd, float ts, 
              float out_min, float out_max, float tau_filter, bool enable_aw)
{
    pid->Kp = kp;
    pid->Ki = ki;
    pid->Kd = kd;
    pid->Ts = ts;
    pid->out_min = out_min;
    pid->out_max = out_max;
    pid->anti_windup_en = enable_aw;

    // Расчет коэффициента ФНЧ: beta = tau / (tau + Ts)
    if (tau_filter > 0.0f) {
        pid->beta = tau_filter / (tau_filter + ts);
    } else {
        pid->beta = 0.0f; // Фильтрация отключена
    }

    PID_Reset(pid);
}

void PID_Reset(pid_controller_t *pid)
{
    pid->integral = 0.0f;
    pid->prev_meas = 0.0f;
    pid->prev_d_term = 0.0f;
}

float PID_Compute(pid_controller_t *pid, float setpoint, float measurement)
{
    // 1. Ошибка регулирования
    float error = setpoint - measurement;

    // 2. Пропорциональная составляющая
    float p_term = pid->Kp * error;

    // 3. Дифференциальная составляющая по измерению (Derivative on Measurement)
    // d/dt(error) = - d/dt(meas) при константной уставке
    float d_meas = (measurement - pid->prev_meas) / pid->Ts;
    float d_raw = -pid->Kd * d_meas;
    
    // Рекурсивный ФНЧ 1-го порядка
    float d_term = (pid->beta * pid->prev_d_term) + ((1.0f - pid->beta) * d_raw);
    pid->prev_d_term = d_term;
    pid->prev_meas = measurement;

    // 4. Предварительная сумма без учета нового приращения интегратора
    float u_pre = p_term + d_term;

    // 5. Anti-Windup Clamping (условное интегрирование)
    bool clamp_high = ((u_pre + pid->integral) >= pid->out_max) && (error > 0.0f);
    bool clamp_low  = ((u_pre + pid->integral) <= pid->out_min) && (error < 0.0f);

    if (!pid->anti_windup_en || (!clamp_high && !clamp_low)) {
        pid->integral += pid->Ki * pid->Ts * error;
    }

    // 6. Формирование ненасыщенного выхода и жесткое ограничение
    float u_total = u_pre + pid->integral;

    if (u_total > pid->out_max) {
        return pid->out_max;
    } else if (u_total < pid->out_min) {
        return pid->out_min;
    }
    
    return u_total;
}
```

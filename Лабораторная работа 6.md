# Проектирование драйвера комплементарного ШИМ с настраиваемым Dead-Time и аппаратным отключением при срабатывании компаратора тока
**Продолжительность:** 4 академических часа

**Целевая аудитория:** Студенты 3–4 курсов 

**Аппаратная база:** Микроконтроллер К1921ВГ01Т (RISC-V) / силовой полумост на MOSFET/IGBT с компаратором токовой защиты

## 1\. Цель работы

- Изучить принципы аппаратного взаимодействия моторного блока **ePWM** с модулем аварийной защиты **Trip-Zone (TZ)** и аналоговым компаратором микроконтроллера К1921ВГ01Т.
- Освоить конфигурирование генератора мертвого времени (**Dead-Band Submodule**) для формирования комплементарных сигналов с программируемыми задержками $t_{RED}$ и $t_{FED}$.
- Настроить аппаратное безакцептное отключение выходов ШИМ в безопасное состояние при превышении порога фазного тока (время реакции $\le 50\text{ нс}$).
- Исследовать режимы автоматического восстановления генерации ШИМ по периоду (**Cycle-by-Cycle**) и блокировки до вмешательства оператора (**One-Shot**).

## 2\. Теоретические сведения

### 2.1. Аварийные режимы силовых стоек и ограничение программного прерывания

При заклинивании ротора, пробое нижнего ключа или коротком замыкании обмоток индуктивность рассеяния не способна сдержать лавинное нарастание тока $di/dt = U_{bus} / L$. Задержка программного прерывания (Context Switch в RISC-V занимает 15–30 тактов плюс время выполнения тела функции — суммарно более $1\text{ мкс}$) неизбежно приводит к тепловому разрушению кристалла транзистора.

Модуль **Trip-Zone** обеспечивает обход процессорного ядра: сигнал аварии от встроенного аналогового компаратора или внешнего пина перегрузки по току аппаратно блокирует логику генератора действий (`Action-Qualifier`) и узла `Dead-Band`, принудительно выставляя на выводах ключей безопасные уровни напряжения за десятки наносекунд.

```
Аналоговый компаратор / Внешний пин FAULT
                 │
                 ▼
     [ Вход Trip-Zone (TZ1 / COMP) ]
                 │
                 ├──────────────────────────────┐
                 ▼ (Аппаратный обход CPU)       ▼
     [ Блок ePWM: логика TZCTL ]         [ Прерывание TZ_IRQ ]
                 │                              │
                 ▼                              ▼
      Принудительный LOW / High-Z       Программная диагностика,
      на затворах ключей (< 50 нс)      счетчик аварий, останов FSM
```

### 2.2. Режимы работы модуля Trip-Zone

В модуле ePWM микроконтроллера К1921ВГ01Т узел Trip-Zone поддерживает два режима обработки аварии:

1. **One-Shot (OSHT):**
	- *Назначение:* Катастрофические отказы (короткое замыкание на шину питания, пробой ключа, перегрев).
		- *Поведение:* Выходы ШИМ немедленно переводятся в заданное состояние (`High-Z` или `Low`) и остаются заблокированными до тех пор, пока прошивка явно не очистит флаг аварии в регистре `TZCLR`.
2. **Cycle-by-Cycle (CBC):**
	- *Назначение:* Поцикловое ограничение пикового тока (Peak Current Control).
		- *Поведение:* Выходы отключаются только на текущий период ШИМ. При наступлении события `CTR = 0` (нового периода) флаг CBC сбрасывается аппаратно, и импульс генерируется заново.

### 2.3. Конфигурация выходов в аварийном состоянии

В регистре `TZCTL` задается состояние выводов `ePWMxA` и `ePWMxB` при фиксации аварии:

- **00b (High-Z):** Высокоимпедансное состояние (драйвер с подтяжкой к земле закрывает оба ключа).
- **01b (Force High):** Принудительная лог. 1 (применяется для динамического закорачивания обмоток на землю в некоторых схемах торможения).
- **10b (Force Low):** Принудительный лог. 0 (основной безопасный режим для полумостов с прямым управлением).
- **11b (Do Nothing):** Блокировка отключена.

## 3\. Расчетные формулы

1. **Порог срабатывания аналогового компаратора тока:** При использовании встроенного компаратора с опорным напряжением от внутреннего ЦАП ($V_{DAC}$) или внешнего резистивного делителя:
	$$
	V_{trip} = V_{ref\_mid} + (I_{limit} \cdot R_{shunt} \cdot G_{opamp})
	$$
	Код 12-битного ЦАП для порога компаратора:
	$$
	\text{DAC\_VAL} = \frac{V_{trip}}{V_{ref}} \cdot 4095
	$$
2. **Расчет мертвого времени Dead-Time:**
	$$
	\text{DBRED} = \text{DBFED} = \frac{t_{dead}}{T_{TBCLK}} = t_{dead} \cdot F_{TBCLK}
	$$

## 4\. Оборудование и инструменты

1. Стенд с микроконтроллером **К1921ВГ01Т** (RISC-V).
2. Двухканальный цифровой осциллограф с полосой от 100 МГц (Канал 1 — затвор верхнего ключа, Канал 2 — сигнал компаратора тока / аварии).
3. Силовой полумост со схемой измерения тока на шунте и тестовой кнопкой / источником напряжения для имитации перегрузки.
4. Программатор JTAG (FTDI FT2232 / J-Link).
5. Toolchain: GCC RISC-V + OpenOCD + библиотека `plib01t`.

## 6\. Пример программной реализации драйвера ШИМ с Trip-Zone

```c
#include "k1921vg01t.h"
#include <stdint.h>
#include <stdbool.h>

#define SYSCLK_HZ           100000000UL
#define PWM_FREQ_HZ         20000UL
#define DEADTIME_TICKS      120 // 1.2 мкс при 100 МГц

// Расчет периода для Up-Down счета: TBPRD = 100 МГц / (2 * 20 кГц) = 2500
#define PWM_TBPRD           (SYSCLK_HZ / (2 * PWM_FREQ_HZ))

static volatile bool fault_flag = false;

/**
 * @brief Инициализация ePWM с комплементарным Dead-Time и защитой Trip-Zone
 */
void ePWM0_Protected_Driver_Init(void)
{
    // 1. Тактирование блока ePWM0
    RCU->HCLKCFG_bit.EPWM0EN = 1;
    RCU->HRSTCFG_bit.EPWM0EN = 1;

    // 2. Настройка базы времени (Time-Base)
    EPWM0->TBCTL_bit.PRDLD = 0;       // Загрузка через Shadow-регистр
    EPWM0->TBPRD = PWM_TBPRD;
    EPWM0->TBCTR = 0;
    EPWM0->TBCTL_bit.CTRMODE = 0x2;   // 0x2 = Up-Down Count (симметричный ШИМ)
    EPWM0->TBCTL_bit.CLKDIV = 0;      // /1
    EPWM0->TBCTL_bit.HSPCLKDIV = 0;   // /1

    // 3. Компаратор скважности (базово 50%)
    EPWM0->CMPCTL_bit.SHDWAMODE = 0;  // Включение Shadow-буфера
    EPWM0->CMPCTL_bit.LOADAMODE = 0;  // Перезагрузка при CTR = 0
    EPWM0->CMPA = PWM_TBPRD / 2;

    // 4. Action-Qualifier: формирование импульса на ePWMxA
    // При счете вверх совпадение CMPA -> LOW; при счете вниз совпадение CMPA -> HIGH
    EPWM0->AQCTLA = (0x1 << 4) | (0x2 << 6);

    // 5. Dead-Band: генерация комплементарной пары с задержками
    EPWM0->DBCTL_bit.IN_MODE = 0;     // Источник задержек — канал ePWMxA
    EPWM0->DBCTL_bit.POLSEL = 2;      // Active High Complementary (инверсия канала B)
    EPWM0->DBCTL_bit.OUT_MODE = 3;    // Включены задержки RED и FED
    EPWM0->DBRED = DEADTIME_TICKS;
    EPWM0->DBFED = DEADTIME_TICKS;

    // 6. Подсистема аварийного отключения Trip-Zone (TZ)
    // Назначаем источник TZ1 в режиме One-Shot (однократная блокировка)
    EPWM0->TZSEL_bit.OSHT1 = 1;

    // Уровни выходов при аварии: принудительный ноль (LOW) для обоих затворов
    EPWM0->TZCTL_bit.TZA = 2;         // 10b = Force Low на ePWMxA
    EPWM0->TZCTL_bit.TZB = 2;         // 10b = Force Low на ePWMxB

    // 7. Прерывание аварийного события TZ
    EPWM0->TZEINT_bit.OST = 1;        // Прерывание по флагу One-Shot
    PLIC_SetPriority(EPWM0_TZ_IRQn, 1);
    PLIC_EnableIRQ(EPWM0_TZ_IRQn);
}

/**
 * @brief Обработчик прерывания аварийного события Trip-Zone
 */
void EPWM0_TZ_IRQHandler(void)
{
    if (EPWM0->TZFLG_bit.OST) 
    {
        fault_flag = true;

        // Здесь выполняется логирование аварии, остановка контуров управления робота
        // Силовые выходы уже аппаратно обесточены!

        // Для ручного перезапуска после устранения аварии необходимо выполнить:
        // EPWM0->TZCLR_bit.OST = 1;
        // EPWM0->TZCLR_bit.INT = 1;

        EPWM0->TZCLR_bit.INT = 1; // Очистка статуса прерывания
    }
}
```

## 8\. Задания для самостоятельного исследования

3. **Реализация конечного автомата восстановления:** Напишите функцию программного автомата защиты: если после аварии One-Shot прошло 3 секунды, а ток вернулся в норму, прошивка производит безопасный рестарт генератора ШИМ с нулевой скважности (плавный пуск).

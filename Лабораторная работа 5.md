# Синхронное с ШИМ измерение падения напряжения на шунте тока через инжектированный канал АЦП с усреднением

**Продолжительность:** 4 академических часа

**Целевая аудитория:** Студенты 3–4 курсов

**Аппаратная база:** Микроконтроллер К1921ВГ01Т (RISC-V) / стенд с драйвером двигателя и нижним шунтом

## 1\. Цель работы

- Изучить физику коммутационных помех ($di/dt$, $du/dt$) и переходных процессов в силовых мостовых преобразователях при импульсном измерении тока.
- Освоить аппаратную синхронизацию аналого-цифрового преобразователя с моторным таймером (**ePWM $\to$ ADC Trigger / SOC**).
- Настроить **инжектированный (высокоприоритетный) секвенсор АЦП** для мгновенного выполнения замера тока с прерыванием фоновых регулярных цепочек преобразования.
- Спроектировать процедуру автоматической калибровки начального смещения нуля усилителя токового шунта (Zero-Current Bias Calibration) и рекурсивный фильтр усреднения отсчетов.

## 2\. Теоретические сведения

### 2.1. Физика измерения тока на нижнем шунте (Low-Side Shunt)

В электроприводах постоянного тока и вентильных двигателях (BLDC/PMSM) измерение тока через резистивный шунт в истоке нижнего ключа полумоста (Low-Side Sensing) является наиболее экономичным и надежным решением, так как не требует высоковольтных изолированных усилителей.

Однако падение напряжения $U_{shunt} = I_{phase} \cdot R_{shunt}$ присутствует на нижнем резисторе **только тогда, когда нижний транзистор стойки открыт** ($Q_L = \text{ON}$), а верхний закрыт ($Q_H = \text{OFF}$).

При симметричной ШИМ с выравниванием по центру (Up-Down Count) счетчик `TBCTR` движется по траектории $0 \to \text{TBPRD} \to 0$:

1. В окрестности вершины счета (`CTR = PRD`) верхний ключ находится в проводящем состоянии.
2. В окрестности нулевой точки счета (**`CTR = 0`**) верхний ключ $Q_H$ гарантированно закрыт, а нижний ключ $Q_L$ открыт.
3. В момент коммутации ключей возникают паразитные высокочастотные колебания (звон емкостей затвора и индуктивностей дорожек). Выборка АЦП должна производиться строго **в середине проводящего состояния нижнего ключа** с задержкой относительно фронта переключения ключа, когда переходный процесс затух.

### 2.2. Инжектированные vs Регулярные каналы АЦП

В контроллерах моторного класса (К1921ВГ01Т, STM32, C2000) каналы АЦП разделены на два типа очередей:

- **Регулярные каналы (Regular):** опрашиваются в фоновом режиме по кругу через DMA (медленно меняющиеся параметры: температура радиатора, напряжение батареи $V_{bus}$, положение потенциометра).
- **Инжектированные каналы (Injected):** обладают наивысшим аппаратным приоритетом. При поступлении триггера строба от ePWM (`CTR = 0` или `CTR = CMP`) контроллер АЦП **немедленно прерывает** фоновую регулярную выборку, выполняет высокоточный замер тока фазы, сохраняет результат в специализированный регистр и возвращается к прерванному регулярному опросу.

### 2.3. Тракт усиления и калибровка нуля

Поскольку сопротивление шунта выбирается малым ($R_{shunt} \approx 5\text{--}50\text{ мОм}$) для снижения тепловых потерь, сигнал усиливается дифференциальным операционным усилителем (ОУ / Current-Sense Amplifier) с коэффициентом $G$:

$$
U_{ADC} = V_{ref\_mid} + (I_{phase} \cdot R_{shunt} \cdot G)
$$

Для измерения знакопеременного тока в схему вводится искусственная средняя точка $V_{ref\_mid} \approx 1.65\text{ В}$. Из-за технологического разброса резисторов смещения и напряжения сдвига ОУ ($V_{os}$) реальный код АЦП при нулевом токе $I = 0$ отличается от идеального значения 2048. Перед запуском ШИМ прошивка обязана выполнить **калибровку нуля**.

## 3\. Расчетные формулы

1. **Связь кода АЦП и физического тока:**
	$$
	I_{meas} = \frac{(\text{ADC\_RAW} - \text{ADC\_OFFSET}) \cdot V_{ref}}{4095 \cdot (R_{shunt} \cdot G)} \quad [\text{А}]
	$$
2. **Калибровка смещения (усреднение $N$ отсчетов до старта силовой части):**
	$$
	\text{ADC\_OFFSET} = \frac{1}{N} \sum_{k=1}^{N} \text{ADC\_RAW}_{I=0}[k]
	$$
3. **Рекурсивный фильтр экспоненциального сглаживания (ФНЧ 1-го порядка):**
	$$
	I_{flt}[k] = \alpha \cdot I_{meas}[k] + (1 - \alpha) \cdot I_{flt}[k-1], \quad \alpha = \frac{T_s}{T_s + \tau}
	$$

## 6\. Пример исходного кода драйвера


```c
#include "k1921vg01t.h"
#include <stdint.h>

#define R_SHUNT_OHMS        0.02f   // Шунт 20 мОм
#define OPAMP_GAIN          20.0f   // Коэффициент усиления ОУ
#define V_REF               3.3f    // Опорное напряжение АЦП
#define ADC_SCALE           (V_REF / (4095.0f * R_SHUNT_OHMS * OPAMP_GAIN))

static volatile uint16_t adc_offset = 2048;
static volatile float current_amps_raw = 0.0f;
static volatile float current_amps_filtered = 0.0f;
static const float filter_alpha = 0.15f; // Постоянная сглаживания

/**
 * @brief Калибровка смещения нуля усилителя тока при отключенном ШИМ
 */
void CurrentSense_Calibrate_Zero(void)
{
    uint32_t sum = 0;
    const uint16_t samples = 1024;

    for (uint16_t i = 0; i < samples; i++) {
        // Программный запуск одиночного преобразования
        ADC->SEQ[0].CTL_bit.SWREQ = 1;
        while (ADC->SEQ[0].CTL_bit.SWREQ); // Ожидание
        sum += (ADC->SEQ[0].DATA & 0x0FFF);
    }
    adc_offset = (uint16_t)(sum / samples);
}

/**
 * @brief Настройка ePWM на аппаратную генерацию импульса запуска АЦП (SOCA)
 */
void ePWM0_EventTrigger_Init(void)
{
    // Настройка узла ET (Event Trigger) блока ePWM0
    EPWM0->ETSEL_bit.SOCAEN = 1;     // Разрешение строба SOCA
    EPWM0->ETSEL_bit.SOCASEL = 1;    // 001b = Триггер при CTR = 0 (центр нижнего ключа)
    EPWM0->ETPS_bit.SOCAPRD = 1;     // Генерировать строб на каждое 1-е событие
}

/**
 * @brief Настройка инжектированного канала АЦП
 */
void ADC_Injected_Current_Init(void)
{
    RCU->CGCFGAHB_bit.ADCEN = 1;
    RCU->RSTDISAHB_bit.ADCEN = 1;

    // Секвенсор 1 настраиваем как инжектированный (высокий приоритет)
    ADC->SEQ[1].CTL_bit.TRIG = 3;    // 3 = Аппаратный триггер от ePWM0 SOCA
    ADC->SEQ[1].CH[0] = 0;           // Канал 0 (вход с ОУ шунта)
    ADC->SEQ[1].CTL_bit.LEN = 0;     // 1 преобразование в цепочке
    ADC->SEQ[1].CTL_bit.PRI = 1;     // Повышенный приоритет (прерывает фоновые цепочки)

    // Прерывание по завершению инжектированного замера
    ADC->SEQ[1].INTEN_bit.EN = 1;
    PLIC_EnableIRQ(ADC_SEQ1_IRQn);

    ADC->SEQ[1].CTL_bit.EN = 1;
    ADC->CTL_bit.ENABLE = 1;
}

/**
 * @brief Обработчик прерывания инжектированного канала АЦП (вызывается на каждом периоде ШИМ)
 */
void ADC_SEQ1_IRQHandler(void)
{
    // 1. Чтение оцифрованного значения из регистра инжектированного секвенсора
    int16_t raw_code = (int16_t)(ADC->SEQ[1].DATA & 0x0FFF);

    // 2. Вычитание откалиброванного нуля и масштабирование в Амперы
    int16_t centered_code = raw_code - (int16_t)adc_offset;
    current_amps_raw = (float)centered_code * ADC_SCALE;

    // 3. Быстрое цифровое экспоненциальное усреднение (ФНЧ)
    current_amps_filtered = (filter_alpha * current_amps_raw) + 
                            ((1.0f - filter_alpha) * current_amps_filtered);

    // 4. Очистка флага прерывания секвенсора
    ADC->SEQ[1].INTCLR = 1;
}
```

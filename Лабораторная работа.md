## 2\. Теоретические сведения

### 2.1. Структура замкнутого контура регулирования

В робототехнических системах управление скоростью вала коллекторного DC-мотора строится по принципу отрицательной обратной связи:

```
Задание W_ref (+)       Ошибка e[k]   +---------------+   U[k]   +--------------+    ШИМ    +------------+        +----------+
---------------->( Σ ) -------------> |  Дискретный   | -------> | Сатуратор и  | --------> | Блок ePWM  | -----> | Двигатель| ---> Вал (W)
                   ^ (-)              | ПИД-регулятор |          | Anti-Windup  |           | + H-мост   |        +----+-----+      |
                   |                  +---------------+          +--------------+           +------------+             |           |
                   |                                                                                                   v           |
                   +----------------------- Оценка скорости W_meas[k] <----------------------------------------- Энкодер + eQEP/eCAP <-+
```

Период дискретизации контура $T_s$ (квант времени вызова регулятора) должен быть строго детерминированным. Для моторных приводов типовое значение лежит в диапазоне $T_s = 1\text{--}10\text{ мс}$ ($100\text{--}1000\text{ Гц}$).

### 2.2. Уравнения дискретного ПИД-регулятора

Классическое параллельное уравнение непрерывного ПИД:

$$
u(t) = K_p \, e(t) + K_i \int_0^t e(\tau)\, d\tau + K_d \, \frac{de(t)}{dt}
$$

Для реализации на микроконтроллере применяется дискретная форма в абсолютном виде (позиционный алгоритм) с шагом $T_s$.

1. **Ошибка регулирования:**
	$$
	e[k] = \omega_{ref}[k] - \omega_{meas}[k]
	$$
2. **Пропорциональная составляющая:**
	$$
	P[k] = K_p \cdot e[k]
	$$
3. **Интегральная составляющая (численное интегрирование по методу прямоугольников вперед или трапеций):**
	$$
	I[k] = I[k-1] + K_i \cdot T_s \cdot e[k]
	$$
4. **Дифференциальная составляющая с фильтром низкой частоты 1-го порядка:** Прямое дифференцирование ошибки приводит к усилению шумов квантования энкодера. Применяется дифференцирование сигнала обратной связи (Derivative on Measurement) с ФНЧ:
	$$
	D[k] = \beta \cdot D[k-1] - (1 - \beta) \cdot \frac{K_d}{T_s} \cdot (\omega_{meas}[k] - \omega_{meas}[k-1]),
	$$
	где $\beta = \frac{\tau_f}{\tau_f + T_s}$, $\tau_f$ — постоянная времени фильтра.
5. **Ограничение насыщения интегратора (Anti-Windup методом зажима / Clamping):** Если суммарный сигнал $U_{unsat}[k] = P[k] + I[k] + D[k]$ выходит за физические пределы коэффициента заполнения ШИМ ($[-U_{max}, +U_{max}]$), накопление интеграла останавливается:
	$$
	I[k] = \begin{cases} I[k-1], & \text{если } U_{unsat} \ge U_{max} \text{ и } e[k] > 0 \\ I[k-1], & \text{если } U_{unsat} \le -U_{max} \text{ и } e[k] < 0 \\ I[k], & \text{иначе} \end{cases}
	$$

### 2.3. Аппаратная защита Trip-Zone (TZ)

При заклинивании редуктора или перегрузке по току ток через обмотки лавинообразно растет. Модуль **Trip-Zone** микроконтроллера К1921ВГ01Т позволяет без программных задержек перевести выходы `ePWMxA`/`ePWMxB` в высокоимпедансное или пассивное состояние по аппаратному сигналу от внешнего компаратора/датчика тока.

### 5.1. Дискретный ПИД-регулятор (`pid_controller.h` и `pid_controller.c`)

C

```
// ========================== pid_controller.h ==========================
#ifndef PID_CONTROLLER_H
#define PID_CONTROLLER_H

#include <stdint.h>
#include <stdbool.h>

typedef struct {
    // Коэффициенты
    float Kp;
    float Ki;
    float Kd;
    float Ts;              // Период дискретизации, с

    // Пределы насыщения выхода
    float out_max;
    float out_min;

    // Внутренние переменные состояния
    float integral;
    float prev_meas;
    float prev_derivative;
    float filter_coeff;    // Коэффициент фильтра D-составляющей (0.0 .. 1.0)
} pid_controller_t;

void PID_Init(pid_controller_t *pid, float kp, float ki, float kd, float ts, float min, float max);
void PID_Reset(pid_controller_t *pid);
float PID_Update(pid_controller_t *pid, float setpoint, float measurement);

#endif
```
C

```
// ========================== pid_controller.c ==========================
#include "pid_controller.h"

void PID_Init(pid_controller_t *pid, float kp, float ki, float kd, float ts, float min, float max)
{
    pid->Kp = kp;
    pid->Ki = ki;
    pid->Kd = kd;
    pid->Ts = ts;
    pid->out_min = min;
    pid->out_max = max;

    // Постоянная времени фильтра дифференциатора: tau = 2 * Ts
    float tau = 2.0f * ts;
    pid->filter_coeff = tau / (tau + ts);

    PID_Reset(pid);
}

void PID_Reset(pid_controller_t *pid)
{
    pid->integral = 0.0f;
    pid->prev_meas = 0.0f;
    pid->prev_derivative = 0.0f;
}

float PID_Update(pid_controller_t *pid, float setpoint, float measurement)
{
    // 1. Ошибка регулирования
    float error = setpoint - measurement;

    // 2. Пропорциональная часть
    float p_term = pid->Kp * error;

    // 3. Дифференциальная часть по сигналу измерения (исключает "удар" при смене уставки)
    float d_meas = (measurement - pid->prev_meas) / pid->Ts;
    float d_term_unfiltered = -pid->Kd * d_meas;
    
    // ФНЧ 1-го порядка для производной
    float d_term = (pid->filter_coeff * pid->prev_derivative) + 
                   ((1.0f - pid->filter_coeff) * d_term_unfiltered);
    pid->prev_derivative = d_term;
    pid->prev_meas = measurement;

    // 4. Предварительный расчет выхода (без интегратора)
    float output_pre = p_term + d_term;

    // 5. Anti-Windup Clamping (зажим интегрирования)
    // Интегрируем только тогда, когда выход не уперся в ограничение,
    // либо знак ошибки способствует выходу из насыщения
    bool saturate_high = (output_pre + pid->integral) >= pid->out_max;
    bool saturate_low  = (output_pre + pid->integral) <= pid->out_min;

    if (!(saturate_high && error > 0.0f) && !(saturate_low && error < 0.0f)) {
        pid->integral += pid->Ki * pid->Ts * error;
    }

    // 6. Итоговый выход и жесткая сатурация
    float output = output_pre + pid->integral;

    if (output > pid->out_max) {
        output = pid->out_max;
    } else if (output < pid->out_min) {
        output = pid->out_min;
    }

    return output;
}
```

### 5.2. Аппаратная защита Trip-Zone и выдача воздействия на мотор

C

```
#include "k1921vg01t.h"
#include "pid_controller.h"

#define PWM_PERIOD_TICKS   2500 // 20 кГц при 100 МГц (Up-Down)

/**
 * @brief Инициализация аппаратной аварийной зоны Trip-Zone блока ePWM0
 */
void ePWM0_TripZone_Config(void)
{
    // 1. Назначение входа TZ1: сигнал перегрузки от внешнего компаратора
    // При аварии (лог. 0 на входе) принудительно гасим каналы ePWM
    EPWM0->TZSEL_bit.OSHT1 = 1; // Однократное аппаратное событие (One-Shot)

    // 2. Состояние выходов при срабатывании аварии: перевод в LOW (безопасное отключение)
    EPWM0->TZCTL_bit.TZA = 2;   // 10b = Force Low на ePWM0A
    EPWM0->TZCTL_bit.TZB = 2;   // 10b = Force Low на ePWM0B

    // 3. Разрешение прерывания по срабатыванию TZ
    EPWM0->TZEINT_bit.OST = 1;
    PLIC_EnableIRQ(EPWM0_TZ_IRQn);
}

/**
 * @brief Выдача управляющего воздействия на силовой каскад
 * @param control Значение от -100.0% до +100.0%
 */
void Motor_Set_Output(float control)
{
    // Ограничение диапазона [-100% .. +100%]
    if (control > 100.0f)  control = 100.0f;
    if (control < -100.0f) control = -100.0f;

    // Определение направления через GPIO реверса или биполярный ШИМ
    if (control >= 0.0f) 
    {
        // Вращение вперед: модуляция стойки A
        uint16_t duty_ticks = (uint16_t)((control / 100.0f) * (float)PWM_PERIOD_TICKS);
        EPWM0->CMPA = duty_ticks;
        // Сигнал направления DIR = 1
        GPIO->OUTENSET_bit.PORTA_PIN2 = 1;
        GPIO->DATAOUTSET_bit.PORTA_PIN2 = 1;
    } 
    else 
    {
        // Вращение назад: модуляция со сменной полярностью
        uint16_t duty_ticks = (uint16_t)(((-control) / 100.0f) * (float)PWM_PERIOD_TICKS);
        EPWM0->CMPA = duty_ticks;
        // Сигнал направления DIR = 0
        GPIO->OUTENSET_bit.PORTA_PIN2 = 1;
        GPIO->DATAOUTCLR_bit.PORTA_PIN2 = 1;
    }
}

### 5.3. Прерывание контура управления (200 Гц)

```
#include "encoder_hybrid_speed.h"

extern hybrid_speed_handle_t speed_sensor;
extern pid_controller_t motor_pid;

volatile float target_speed_rpm = 600.0f; // Уставка скорости
volatile float current_speed_rpm = 0.0f;
volatile float control_effort = 0.0f;

// Обработчик таймера дискретного контура (вызывается каждые 5 мс)
void Timer_5ms_Control_IRQHandler(void)
{
    // 1. Опрос гибридного датчика скорости
    Hybrid_Speed_Process(&speed_sensor);
    current_speed_rpm = Hybrid_Speed_GetRPM(&speed_sensor);

    // 2. Расчет шага ПИД-регулятора
    control_effort = PID_Update(&motor_pid, target_speed_rpm, current_speed_rpm);

    // 3. Выдача ШИМ на мотор
    Motor_Set_Output(control_effort);

    // 4. Сброс флага прерывания таймера
    TIMER0->INTCLR = 1;
}

## 7\. Обработка результатов и контрольные вопросы

### Анализ переходного процесса

Студент должен экспортировать массивы отсчетов времени, уставки и измеренной скорости в формат CSV и построить график, на котором определяются:

1. **Перерегулирование:** $\sigma = \frac{\omega_{max} - \omega_{ref}}{\omega_{ref}} \cdot 100\%$.
2. **Время регулирования $t_{reg}$:** время входа переходной кривой в 5%-ную трубку вокруг $\omega_{ref}$.
3. **Статическая ошибка:** $\Delta \omega_{st} = \vert{}\omega_{ref} - \omega_{ust}\vert{}$.

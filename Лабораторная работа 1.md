## 2\. Теоретические сведения

### 2.1. Подсистема тактирования и модуль PLL К1921ВГ01Т

После аппаратного сброса ядро RISC-V начинает выполнение инструкций от внутреннего низкоточного RC-генератора или прямого сигнала внешнего резонатора. Для достижения максимального быстродействия (100 МГц) и детерминизма времени контуров управления включается внешний кварцевый генератор (HSE, обычно 12 МГц или 16 МГц) и модуль PLL.

Входная частота PLL ($F_{IN}$) умножается и делится согласно формуле коэффициентов обратной связи:

$$
F_{VCO} = F_{IN} \cdot \frac{NF}{NR}
$$

$$
F_{OUT} = \frac{F_{VCO}}{OD} = F_{IN} \cdot \frac{NF}{NR \cdot OD}
$$

где:

- $NR$ — входной предделитель (Reference Divider),
- $NF$ — множитель обратной связи (Feedback Multiplier),
- $OD$ — выходной делитель (Output Divider).

> **Важно:** Переключение системной шины `SYSCLK` на выход PLL разрешено производить **только после выставления аппаратного флага захвата частоты** (`PLL_LOCKED`). Попытка переключить источник тактирования на нестабилизированный PLL приведет к аппаратному зависанию ядра или сбою конвейера инструкций.

### 2.2. Архитектура прерываний RISC-V (Privileged Architecture)

В отличие от контроллера прерываний ARM Cortex-M (NVIC), процессорное ядро RISC-V RV32IMAC обрабатывает прерывания через регистры управления и состояния (CSR — Control and Status Registers):

- `mstatus` (Machine Status): глобальный бит разрешения прерываний машинного уровня `MIE` (Machine Interrupt Enable, бит 3).
- `mie` (Machine Interrupt Enable Register): маскирование отдельных источников (таймеры, программные прерывания, внешние прерывания `MEIE`).
- `mtvec` (Machine Trap-Vector Base-Address): базовый адрес обработчика исключений и прерываний. Поддерживает два режима:
	- **Direct Mode (младшие биты = `00`):** все прерывания и исключения переходят по единому аппаратному адресу.
		- **Vectored Mode (младшие биты = `01`):** прерывание с номером $i$ переходит по адресу `BASE + 4 * i`.
- Внешние периферийные прерывания кристалла (таймеры, ePWM, UART) агрегируются платформенным контроллером прерываний **PLIC** (Platform-Level Interrupt Controller), где настраиваются их приоритеты и шлюзы к ядру.

### 2.3. Концепция неблокирующего диспетчера задач

В контурах реального времени использование функций жесткой задержки (`delay_ms()`, пустые циклы `for`/`while`) категорически запрещено: процессор простаивает и теряет события от датчиков и коммуникационных шин.

Архитектура неблокирующего кооперативного диспетчера:

1. **Аппаратный таймер (1 кГц):** инкрементирует системный счетчик миллисекунд `sys_tick_ms` и декрементирует индивидуальные счетчики интервалов задач. При обнулении счетчика выставляется флаг готовности задачи к исполнению `task.ready = 1`.
2. **Суперцикл (`main while(1)`):** последовательно обходит таблицу задач. Если флаг `ready` выставлен, вызывается функция задачи, после чего флаг сбрасывается, а счетчик тайм-аута перезаряжается заданным периодом.
       ```
Прерывание базового таймера (каждые 1 мс)
                     │
                     ▼
          sys_tick_ms++
          Проверка периодов задач в массиве tasks[]
          tasks[i].counter--
          Если counter == 0 -> tasks[i].ready = 1, counter = period
                     │
                     ▼
               Выход из ISR
                     │
      ──────────────────────────────────────────────
                     │
         Фоновый суперцикл main()
                     │
                     ▼
         Циклический опрос tasks[i]:
         Если tasks[i].ready == 1:
            tasks[i].ready = 0;
            tasks[i].task_fn(); // Вызов пользовательской функции

### 2.4. Базовый 32-разрядный таймер TMR (TIMER) в К1921ВГ01Т

В микроконтроллере К1921ВГ01Т подсистемы общего назначения включают классические 32-битные таймеры с декрементным счетом (Down-counter):

- **Регистр начального значения (`LOAD`):** число тактов, отсчитываемых до генерации прерывания.
- **Регистр текущего значения (`VALUE`):** мгновенный отсчет таймера.
- **Регистр управления (`CTRL`):** биты разрешения работы (`EN`), режима перезагрузки (`MODE`: периодический или однократный), разрешения прерывания (`INTEN`).
- **Регистр флага и очистки прерывания (`INTCLR`):** сброс статусного флага при выходе из обработчика.

При тактовой частоте шины $F_{TIMCLK} = 100\text{ МГц}$ требуемый интервал $T = 1.0\text{ мс}$ рассчитывается как:

$$
\text{LOAD} = F_{TIMCLK} \cdot T - 1 = 100\,000\,000 \cdot 0.001 - 1 = 99\,999
$$

## 5\. Полный листинг программного обеспечения

### 5.1. Заголовочный файл диспетчера (`scheduler.h`)



```C
#ifndef SCHEDULER_H
#define SCHEDULER_H

#include <stdint.h>
#include <stdbool.h>

#define MAX_TASKS 8

typedef void (*task_func_t)(void);

typedef struct {
    task_func_t p_func;        // Указатель на исполняемую функцию
    uint32_t period_ms;        // Период перезапуска, мс
    uint32_t counter_ms;       // Текущий обратный отсчет
    bool is_ready;             // Флаг готовности к выполнению
} task_descriptor_t;

void Scheduler_Init(void);
bool Scheduler_AddTask(task_func_t p_func, uint32_t period_ms);
void Scheduler_Tick_ISR(void);
void Scheduler_Run(void);

#endif // SCHEDULER_H
```

### 5.2. Реализация диспетчера (`scheduler.c`)


```c
#include "scheduler.h"

static task_descriptor_t task_list[MAX_TASKS];
static uint8_t task_count = 0;
static volatile uint32_t sys_tick_counter = 0;

void Scheduler_Init(void)
{
    task_count = 0;
    sys_tick_counter = 0;
    for (uint8_t i = 0; i < MAX_TASKS; i++) {
        task_list[i].p_func = 0;
        task_list[i].period_ms = 0;
        task_list[i].counter_ms = 0;
        task_list[i].is_ready = false;
    }
}

bool Scheduler_AddTask(task_func_t p_func, uint32_t period_ms)
{
    if ((task_count >= MAX_TASKS) || (p_func == 0) || (period_ms == 0)) {
        return false;
    }

    task_list[task_count].p_func = p_func;
    task_list[task_count].period_ms = period_ms;
    task_list[task_count].counter_ms = period_ms;
    task_list[task_count].is_ready = false;
    task_count++;
    return true;
}

// Вызывается из аппаратного прерывания базового таймера каждые 1 мс
void Scheduler_Tick_ISR(void)
{
    sys_tick_counter++;

    for (uint8_t i = 0; i < task_count; i++) {
        if (task_list[i].counter_ms > 0) {
            task_list[i].counter_ms--;
            if (task_list[i].counter_ms == 0) {
                task_list[i].is_ready = true;
                task_list[i].counter_ms = task_list[i].period_ms;
            }
        }
    }
}

// Неблокирующий суперцикл в main()
void Scheduler_Run(void)
{
    for (uint8_t i = 0; i < task_count; i++) {
        if (task_list[i].is_ready) {
            task_list[i].is_ready = false;
            task_list[i].p_func(); // Вызов целевой задачи
        }
    }
}
```

### 5.3. Инициализация аппаратуры и суперцикл (`main.c`)



```c
#include "k1921vg01t.h"
#include "scheduler.h"

#define HSE_FREQ_HZ         12000000UL  // Внешний кварц 12 МГц
#define SYSCLK_TARGET_HZ    100000000UL // Целевая частота ядра 100 МГц

// Порт тестового вывода и светодиода
#define LED_PIN_MASK        (1 << 0)    // Пин PORTA.0 (Heartbeat LED)
#define DEBUG_PIN_MASK      (1 << 1)    // Пин PORTA.1 (Осциллографический тест)

/**
 * @brief Разгон ядра до 100 МГц через HSE и PLL
 *        Формула: F_out = 12 МГц * 50 / (3 * 2) = 100 МГц
 */
void System_Clock_Init(void)
{
    // 1. Включение внешнего кварца (HSE)
    RCU->CGCFGAHB_bit.SCUEN = 1;
    SCU->OSCCFG_bit.HSEEN = 1;
    while (!SCU->OSCSTAT_bit.HSERDY); // Ожидание стабилизации кварца

    // 2. Настройка предделителей PLL:
    // NR = 3, NF = 50, OD = 2
    SCU->PLLCFG_bit.PLLNR = 3 - 1;
    SCU->PLLCFG_bit.PLLNF = 50 - 1;
    SCU->PLLCFG_bit.PLLOD = 2 - 1;
    SCU->PLLCFG_bit.PLLSRC = 1;       // Источник PLL — внешний кварц HSE

    // 3. Запуск контура PLL
    SCU->PLLCFG_bit.PLLEN = 1;
    while (!SCU->PLLSTAT_bit.PLLLOCK); // Ждем захвата частоты (аппаратный LOCK)

    // 4. Переключение тактирования системы на PLL
    SCU->SYSCLKCFG_bit.SYSSEL = 2;     // 2 = PLL output
    while (SCU->SYSCLKSTAT_bit.SYSSEL != 2);
}

/**
 * @brief Инициализация базового таймера TMR0 на период 1.0 мс
 */
void TMR0_1ms_Init(void)
{
    // Включение тактирования блока таймера
    RCU->CGCFGAHB_bit.TMR0EN = 1;
    RCU->RSTDISAHB_bit.TMR0EN = 1;

    // Останов таймера для настройки
    TMR0->CTRL_bit.ENABLE = 0;

    // Загрузка счетчика: 100 МГц * 0.001 с - 1 = 99999
    TMR0->LOAD = (SYSCLK_TARGET_HZ / 1000UL) - 1;

    // Режим счета: периодический (Periodic), разрешение прерывания
    TMR0->CTRL_bit.MODE = 1;
    TMR0->CTRL_bit.INTEN = 1;

    // Разрешение прерывания в контроллере PLIC микроконтроллера
    PLIC_SetPriority(TMR0_IRQn, 1);
    PLIC_EnableIRQ(TMR0_IRQn);

    // Запуск таймера
    TMR0->CTRL_bit.ENABLE = 1;
}

/**
 * @brief Обработчик аппаратного прерывания TMR0
 */
void TMR0_IRQHandler(void)
{
    // Очистка аппаратного флага прерывания таймера
    TMR0->INTCLR = 1;

    // Обновление тайм-аутов планировщика
    Scheduler_Tick_ISR();
}

/**
 * @brief Разрешение машинных прерываний ядра RISC-V (CSR)
 */
static inline void RISCV_Global_Interrupt_Enable(void)
{
    __asm volatile("csrs mstatus, %0" :: "r"(0x08)); // Установка бита MIE (Machine Interrupt Enable)
    __asm volatile("csrs mie, %0"     :: "r"(0x800)); // Установка бита MEIE (Machine External Interrupt Enable)
}

// ============================================================================
// Пользовательские периодические задачи
// ============================================================================

// Задача 1: Осциллографический меандр 50 Гц (переключение каждые 10 мс)
void Task_Toggle_DebugPin(void)
{
    GPIOA->DATAOUT ^= DEBUG_PIN_MASK;
}

// Задача 2: Статусный индикатор Heartbeat (переключение каждые 200 мс)
void Task_Blink_LED(void)
{
    GPIOA->DATAOUT ^= LED_PIN_MASK;
}

// Задача 3: Симуляция периодического контура робота (каждые 100 мс)
void Task_Robot_Sensors_Update(void)
{
    // Неблокирующий опрос датчиков и обновление флагов состояния
}

// ============================================================================
// Главная функция
// ============================================================================
int main(void)
{
    // 1. Тактирование 100 МГц
    System_Clock_Init();

    // 2. Настройка GPIO на вывод (LED и Debug pin)
    RCU->CGCFGAHB_bit.GPIOAEN = 1;
    GPIOA->OUTENSET = LED_PIN_MASK | DEBUG_PIN_MASK;

    // 3. Инициализация диспетчера и добавление задач
    Scheduler_Init();
    Scheduler_AddTask(Task_Toggle_DebugPin, 10);     // Каждые 10 мс
    Scheduler_AddTask(Task_Robot_Sensors_Update, 100); // Каждые 100 мс
    Scheduler_AddTask(Task_Blink_LED, 200);           // Каждые 200 мс

    // 4. Запуск 1 мс таймера и включение прерываний RISC-V
    TMR0_1ms_Init();
    RISCV_Global_Interrupt_Enable();

    // 5. Неблокирующий суперцикл диспетчера
    while (1) {
        Scheduler_Run();
    }
}

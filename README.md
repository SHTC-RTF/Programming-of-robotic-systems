# Programming-of-robotic-systems
Материалы учебного курса "Программирование робототехнических систем"

### Модуль 1. Архитектура МК, система тактирования

 **Общая цель:** инициализация кристалла, понимание системного тактирования, настройка неблокирующего диспетчера и периодических прерываний.

- Системная архитектура: внутренние шинные коммутаторы, контроллер тактирования RCU/SCU (настройка PLL и делителей частоты).
- Обработка исключений и прерываний RISC-V: регистры управления и состояния (CSR: `mstatus`, `mie`, `mtvec`, `mcause`), работа контроллера PLIC/ECLIC.
- Таймер машинного уровня (mtime / mtimecmp) и системные прерывания. Настройка DMA-контроллера микросхемы.

- **Практикум 1-2:**
    - Лаб 1: Базовая инициализация PLL, настройка периодического прерывания базового таймера (период 1 мс) для диспетчера задач без блокирующих функций.
    - Лаб 2: Непрерывная передача калибровочного буфера данных через DMA по запросу от таймера.
### Модуль 2. Получение и цифровая фильтрация данных с датчиков робота

 **Общая  цель:** измерение аналоговых величин (ток, напряжение), опрос цифровых датчиков (IMU, ToF) и датчиков положения (энкодеры).
    - Модуль АЦП: последовательный опрос каналов секвенсором, запуск измерений по событию от блока ePWM для синхронного замера тока фазы.
    - Модуль eQEP (Enhanced Quadrature Encoder Pulse): аппаратный счетчик квадратурных импульсов, детектирование индексной метки Z, встроенный таймер для расчета скорости привода.
    - Цифровые интерфейсы: блоки SPI/SSI и I2C, прямое управление регистрами передачи FIFO.
- **Практикум 3–5:**
    - Лаб 3: Опрос 6-осевого IMU по SPI/DMA, программная реализация комплементарного фильтра для вычисления угла дифферента и крена.
    - Лаб 4: Считывание квадратурного энкодера (на К1921 — через `eQEP`) с вычислением линейной скорости и защитой от переполнения счетчика.
    - Лаб 5: Синхронное с ШИМ измерение падения напряжения на шунте тока через инжектированный канал АЦП с усреднением.
### Модуль 3. Программирование приводов и силовых преобразователей

- **Общая цель:** формирование управляющих сигналов для ключей, регулирование скорости и положения, безопасное переключение.
    - Специализированный модуль ePWM: синхронизация модулей ШИМ, настройка регистров периода, сравнения (CMPA/CMPB), мертвого времени (Dead-Band Generator) и модуля отсечки по аварии (Trip-Zone).
    - Дискретный ПИД-регулятор скорости коллекторного мотора с фиксацией перегрузки через Trip-Zone.
    - Управление трехфазным инвертором BLDC с использованием встроенных компараторов и триггеров защиты К1921.
- **Практикум 6–8:**
	- Лаб 6: Проектирование драйвера комплементарного ШИМ с настраиваемым Dead-Time и аппаратным отключением при срабатывании компаратора тока.
    - Лаб 7: Дискретный ПИД-регулятор скорости DC-мотора с anti-windup (ограничением интегрального насыщения) и фильтром дифференциальной составляющей.
    - Лаб 8: Алгоритм шестишаговой коммутации BLDC-мотора по сигналам от трех встроенных цифровых датчиков Холла.
### Модуль 4. Промышленные коммуникации робототехнических комплексов

- **Общая цель:** объединение приводов и сенсорных плат в локальную сеть, помехоустойчивый обмен с верхним уровнем (ROS / бортовой компьютер).
    - UART: прием пакетов произвольной длины с контролем аппаратного тайм-аута шины.
     - Контроллер CAN: настройка битовой скорости (BRP, TSEG1, TSEG2), конфигурация буферов сообщений и фильтров идентификаторов под шинный протокол робота.
      - Формирование кадров телеметрии и прием управляющих заданий.
- **Практикум 9–10:**
     - Лаб 9: Реализация надежного бинарного протокола типа «Запрос–Ответ» и потоковой телеметрии по UART с вычислением контрольной суммы CRC.
     - Лаб 10: Построение локальной двухточечной CAN-сети: передача угла поворота вала и тока с узла привода на управляющий узел.
 
### Модуль 5. Системное ПО реального времени (RTOS) и итоговая интеграция

- **Общая  цель:** распараллеливание контуров управления, опрос датчиков и коммуникация в рамках операционной системы реального времени.
    - FreeRTOS (официальный порт RISC-V: переключение контекста через прерывание машинного программного прерывания `MSIP` / `mtime`).
    - Специфика выделения стека, выравнивания данных и использования аппаратного FPU ядра RISC-V. 

### Итоговый курсовой проект: 
Разработка встроенного программного обеспечения блока управления колесной платформой или поворотным приводом манипулятора:
    1. Прием команд скорости по шине CAN/UART.
    2. ПИД-регулирование частоты вращения двух двигателей по энкодерам.
    3. Опрос IMU и аварийная остановка при опрокидывании или превышении предельного тока.
    4. Отправка пакетов телеметрии с частотой не менее 50 Гц под управлением FreeRTOS.

# Шестишаговая (трапецеидальная) 120-градусная коммутация трехфазного BLDC-двигателя по сигналам встроенных датчиков Холла

**Продолжительность:** 4 академических часа

**Целевая аудитория:** Студенты 3–4 курсов

**Аппаратная платформа:** Микроконтроллер К1921ВГ01Т (RISC-V) / трехфазный инвертор со стендовым BLDC-мотором

## 1\. Цель работы

- Изучить электромеханический принцип работы вентильного электродвигателя с постоянными магнитами (BLDC) и формирование вращающегося вектора магнитного поля статора при дискретной коммутации.
- Освоить аппаратную обработку сигналов трех встроенных дискретных датчиков Холла ($H_A, H_B, H_C$) с использованием прерываний по изменению состояния (EXTI / Pin Change Interrupt) и фильтрацией дребезга.
- Построить и запрограммировать таблицу состояний шестишаговой (120-градусной) коммутации шести силовых ключей трехфазного инвертора ($U_H, U_L, V_H, V_L, W_H, W_L$) с генерацией ШИМ на верхних или нижних ключах.
- Реализовать реверс направления вращения вала (CW/CCW) и алгоритм вычисления скорости по периоду между срабатываниями датчиков Холла.

## 2\. Теоретические сведения

### 2.1. Принцип шестишаговой 120-градусной коммутации

В трехфазном BLDC-двигателе обмотки статора ($U, V, W$) соединены по схеме «звезда» с изолированной нейтралью (или «треугольник»). Ротор представляет собой постоянный магнит с числом пар полюсов $p$.

В каждый момент времени (в пределах электрического сектора $60^\circ_{эл}$) ток протекает строго через две фазы, соединенные последовательно:

- Одна фаза подключена к шине питания $+V_{bus}$ через открытый верхний транзистор стойки (**High-Side**).
- Вторая фаза подключена к шине $GND$ через открытый нижний транзистор стойки (**Low-Side**).
- Третья фаза остается **отключенной (плавающей, High-Z)**. В ней наводится трапецеидальная противо-ЭДС (Back-EMF).

![120-градусная коммутация фаз по секторам, создано искусственным интеллектом](https://encrypted-tbn0.gstatic.com/images?q=tbn:ANd9GcT3_qBFD-pThH7ELRuCQYDwrKqYj0rQJxIma5AMZOTtP3Qeb4Jzfl6g5zQo&s=10)

120-градусная коммутация фаз по секторам. Источник: NXP Community - NXP Semiconductors.

За один полный электрический оборот ($360^\circ_{эл}$) инвертор проходит 6 дискретных состояний. Связь электрического угла с механическим углом вала ротора:

$$
\theta_{эл} = p \cdot \theta_{мех}
$$

### 2.2. Датчики положения ротора (Датчики Холла)

В пазы статора под углом $120^\circ_{эл}$ (или $60^\circ_{эл}$) устанавливаются три дискретных магниточувствительных датчика Холла. При вращении ротора они формируют 3-битный цифровой код:


$$\text{Hall\_Code} = (H_C \ll 2) \mid (H_B \ll 1) \mid H_A$$


Поскольку датчики сдвинуты на $120^\circ$, комбинации `000b` (0) и `111b` (7) являются **запрещенными** и свидетельствуют об обрыве шлейфа датчиков или повреждении питания сенсоров. Шесть рабочих кодов взаимно однозначно соответствуют секторам коммутации.

## 3\. Расчетные соотношения

1. **Расчет частоты вращения по периоду импульсов датчиков Холла:** Каждое срабатывание любого из трех датчиков Холла соответствует повороту ротора на угол $\Delta \theta_{эл} = 60^\circ = \frac{\pi}{3}\text{ рад}$.
	За один механический оборот генерируется $N_{comm} = 6 \cdot p$ прерываний коммутации.
	Если измеренный интервал между двумя фронтами равен $\Delta t_{hall}$ (секунды):
	$$
	\omega = \frac{60}{6 \cdot p \cdot \Delta t_{hall}} = \frac{10}{p \cdot \Delta t_{hall}} \quad [\text{об/мин}]
	$$
2. **Частота коммутации при максимальных оборотах:** При $n = 6000\text{ об/мин}$ и числе пар полюсов $p = 4$:
	$$
	F_{comm} = \frac{n \cdot 6 \cdot p}{60} = \frac{6000 \cdot 24}{60} = 2400\text{ Гц} \implies \Delta t_{hall} \approx 416\text{ мкс}
	$$

## 4\. Оборудование и инструменты

1. Стендовый контроллер **К1921ВГ01Т** (RISC-V).
2. Трехфазный инвертор (3 полумоста с драйверами затворов и входом `FAULT`).
3. Бесколлекторный двигатель постоянного тока (BLDC 12 В, $p = 4$ или $p = 7$) со встроенными датчиками Холла.
4. Источник питания 12 В 5 А с ограничением тока.
5. Четырехканальный цифровой осциллограф или логический анализатор (для контроля сигналов Холла и фазных напряжений).
6. Toolchain: GCC RISC-V + OpenOCD + GUI-плоттер по UART.

## 6\. Пример исходного кода программы управления

```c
#include "k1921vg01t.h"
#include <stdint.h>
#include <stdbool.h>

#define POLE_PAIRS          4       // Число пар полюсов BLDC
#define PWM_PERIOD_TICKS    2500    // 20 кГц при 100 МГц (Up-Down)

typedef enum {
    DIR_CW  = 0,
    DIR_CCW = 1
} motor_dir_t;

static volatile motor_dir_t current_dir = DIR_CW;
static volatile uint16_t target_duty = 500; // Скважность (0 .. PWM_PERIOD_TICKS)
static volatile uint32_t hall_dt_ticks = 0;
static volatile float current_rpm = 0.0f;

/**
 * @brief Аппаратная смена состояния полумостов инвертора
 */
void BLDC_Set_Phase_States(uint8_t u_state, uint8_t v_state, uint8_t w_state)
{
    // u_state: 0 = High-Z (OFF), 1 = PWM (High-Side), 2 = ON (Low-Side)
    
    // Фаза U (ePWM0)
    if (u_state == 1) {
        EPWM0->CMPA = target_duty;
        EPWM0->AQCSFRC_bit.CSFA = 0; // ШИМ активен
        EPWM0->AQCSFRC_bit.CSFB = 1; // Нижний ключ управляется Dead-Band
    } else if (u_state == 2) {
        EPWM0->AQCSFRC_bit.CSFA = 1; // Принудительный 0 на верхнем ключе
        EPWM0->AQCSFRC_bit.CSFB = 2; // Принудительная 1 на нижнем ключе (GND)
    } else {
        EPWM0->AQCSFRC_bit.CSFA = 1; // Оба ключа закрыты (High-Z)
        EPWM0->AQCSFRC_bit.CSFB = 1;
    }

    // Фаза V (ePWM1)
    if (v_state == 1) {
        EPWM1->CMPA = target_duty;
        EPWM1->AQCSFRC_bit.CSFA = 0;
        EPWM1->AQCSFRC_bit.CSFB = 1;
    } else if (v_state == 2) {
        EPWM1->AQCSFRC_bit.CSFA = 1;
        EPWM1->AQCSFRC_bit.CSFB = 2;
    } else {
        EPWM1->AQCSFRC_bit.CSFA = 1;
        EPWM1->AQCSFRC_bit.CSFB = 1;
    }

    // Фаза W (ePWM2)
    if (w_state == 1) {
        EPWM2->CMPA = target_duty;
        EPWM2->AQCSFRC_bit.CSFA = 0;
        EPWM2->AQCSFRC_bit.CSFB = 1;
    } else if (w_state == 2) {
        EPWM2->AQCSFRC_bit.CSFA = 1;
        EPWM2->AQCSFRC_bit.CSFB = 2;
    } else {
        EPWM2->AQCSFRC_bit.CSFA = 1;
        EPWM2->AQCSFRC_bit.CSFB = 1;
    }
}

/**
 * @brief Шаг 6-шаговой коммутации по коду Холла
 */
void BLDC_Commutate(uint8_t hall_code)
{
    // Таблица коммутации для прямого вращения (CW)
    // 0 = OFF, 1 = PWM_H, 2 = ON_L
    if (current_dir == DIR_CW) 
    {
        switch (hall_code) {
            case 1: BLDC_Set_Phase_States(1, 2, 0); break; // U -> V
            case 3: BLDC_Set_Phase_States(1, 0, 2); break; // U -> W
            case 2: BLDC_Set_Phase_States(0, 1, 2); break; // V -> W
            case 6: BLDC_Set_Phase_States(2, 1, 0); break; // V -> U
            case 4: BLDC_Set_Phase_States(2, 0, 1); break; // W -> U
            case 5: BLDC_Set_Phase_States(0, 2, 1); break; // W -> V
            default:
                // Аварийный код 0 или 7: глушим инвертор
                BLDC_Set_Phase_States(0, 0, 0);
                break;
        }
    } 
    else // DIR_CCW
    {
        switch (hall_code) {
            case 1: BLDC_Set_Phase_States(2, 1, 0); break; // V -> U
            case 3: BLDC_Set_Phase_States(2, 0, 1); break; // W -> U
            case 2: BLDC_Set_Phase_States(0, 2, 1); break; // W -> V
            case 6: BLDC_Set_Phase_States(1, 2, 0); break; // U -> V
            case 4: BLDC_Set_Phase_States(1, 0, 2); break; // U -> W
            case 5: BLDC_Set_Phase_States(0, 1, 2); break; // V -> W
            default:
                BLDC_Set_Phase_States(0, 0, 0);
                break;
        }
    }
}

/**
 * @brief Обработчик внешнего прерывания по изменению состояния датчиков Холла
 */
void GPIO_Hall_IRQHandler(void)
{
    // 1. Измерение периода времени между шагами коммутации (таймер скорости)
    uint32_t now = TMR0->VALUE;
    static uint32_t last_time = 0;
    hall_dt_ticks = last_time - now; // Декрементный счетчик
    last_time = now;

    // Расчет скорости: RPM = (10 * F_clk) / (p * dt_ticks)
    if (hall_dt_ticks > 0) {
        current_rpm = (10.0f * 100000000.0f) / ((float)POLE_PAIRS * (float)hall_dt_ticks);
    }

    // 2. Чтение 3 бит датчиков Холла (пины PORTC.0, PORTC.1, PORTC.2)
    uint8_t hall_a = (GPIOC->DATA >> 0) & 0x01;
    uint8_t hall_b = (GPIOC->DATA >> 1) & 0x01;
    uint8_t hall_c = (GPIOC->DATA >> 2) & 0x01;
    uint8_t hall_code = (hall_c << 2) | (hall_b << 1) | hall_a;

    // 3. Немедленная аппаратная коммутация фаз
    BLDC_Commutate(hall_code);

    // 4. Сброс флагов прерывания GPIO
    GPIOC->INTCLR = (1 << 0) | (1 << 1) | (1 << 2);
}
```

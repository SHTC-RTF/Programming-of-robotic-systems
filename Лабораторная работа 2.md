# Лабораторная работа №2: Высокоскоростной сбор данных со встроенного АЦП через DMA по аппаратному триггеру таймера в микроконтроллере К1921ВГ01Т (RISC-V)

## 2\. Теоретические сведения

### 2.1. Концепция автономного измерительного тракта

В контурах управления робототехническими системами (замеры токов фаз двигателей, сигналы тензомостов, аналоговые датчики расстояния) опрос АЦП в режиме программного опроса флагов готовности (`polling`) или единичных прерываний неприменим:

- Порождает фазовый джиттер времени дискретизации из-за переменной задержки входа в прерывание.
- Непроизводительно расходует вычислительные ресурсы ядра процессора при высоких частотах дискретизации ($>50\text{ кГц}$).

Решение проблемы — аппаратная связка трех блоков:

```
[ Таймер TMR / ePWM ] ──(Аппаратный строб)──> [ Секвенсор АЦП (ADC) ]
                                                        │
                                                 (Запрос DMA_REQ)
                                                        ▼
[ Буфер ОЗУ (Ping-Pong) ] <──(Шина AHB)─────── [ Контроллер DMA ]
```
1. **Таймер** формирует сетку квантования времени с периодом $T_s$.
2. По фронту события таймер генерирует внутренний триггер запуска АЦП.
3. **АЦП** выполняет выборку и преобразование напряжения на аналоговом входе, помещает результат в FIFO/регистр данных и выставляет запрос контроллеру DMA.
4. **Контроллер DMA** считывает значение из регистра АЦП и переносит его в оперативную память, освобождая процессор.

### 2.2. Архитектура АЦП К1921ВГ01Т

Микроконтроллер оснащен 12-разрядным быстродействующим SAR АЦП:

- **Время преобразования:** тактируется от специализированного делителя частоты (до $1\text{--}2\text{ Мвыб/с}$).
- **Секвенсор:** позволяет настраивать цепочки последовательного опроса заданных каналов (например, сначала канал токового шунта `CH0`, затем напряжение шины `CH1`).
- **Источники триггера:** программный запуск, внешние пины, совпадение счетчика базовых таймеров `TMR`, сигналы от блоков `ePWM`.

### 2.3. Контроллер DMA и схема Double Buffering

Контроллер DMA использует дескрипторы каналов передачи в памяти. Для непрерывного потокового сбора данных организуется схема с буфером половинного заполнения:

```
┌───────────────────────┬───────────────────────┐
Общий буфер ОЗУ:  │   Буфер A (Ping)      │   Буфер B (Pong)      │
                  │   [0 ... N-1]         │   [N ... 2N-1]        │
                  └───────────────────────┴───────────────────────┘
                                ▲                       ▲
                                │                       │
              Прерывание Half-Transfer (HT)   Прерывание Transfer-Complete (TC)
              DMA заполняет Pong,             DMA заполняет Ping,
              CPU обрабатывает Ping           CPU обрабатывает Pong
```

Это гарантирует отсутствие состояния гонки данных: ядро никогда не производит чтение из той области памяти, в которую в этот же момент производит запись контроллер DMA.

## 3\. Расчетные соотношения

1. **Частота дискретизации АЦП ($F_s$):** При тактовой частоте таймера $F_{TIMCLK} = 100\text{ МГц}$ требуемое значение периода загрузки `LOAD`:
	$$
	\text{LOAD} = \frac{F_{TIMCLK}}{F_s} - 1
	$$
2. **Перевод 12-разрядного кода АЦП в физическое напряжение:** При опорном напряжении $V_{REF} = 3.3\text{ В}$:
	$$
	U_{in} = \frac{\text{ADC\_DATA}}{4095} \cdot V_{REF} \quad [\text{В}]
	$$
3. **Цифровой фильтр скользящего среднего по $M$ точкам:**
	$$
	y[k] = \frac{1}{M} \sum_{i=0}^{M-1} x[k-i]
	$$

## 6\. Пример исходного кода драйвера АЦП + DMA


```c
#include "k1921vg01t.h"
#include <stdint.h>
#include <stdbool.h>

#define BUFFER_HALF_SIZE    64
#define BUFFER_TOTAL_SIZE   (BUFFER_HALF_SIZE * 2)

// Буфер данных в ОЗУ под управлением DMA
static uint16_t adc_dma_buffer[BUFFER_TOTAL_SIZE] __attribute__((aligned(4)));

// Буфер для вычисленных усредненных значений
static float adc_filtered_voltage[BUFFER_HALF_SIZE];

/**
 * @brief Инициализация таймера TMR1 в качестве аппаратного триггера АЦП
 */
void TMR1_Trigger_Init(uint32_t trigger_freq_hz)
{
    RCU->CGCFGAHB_bit.TMR1EN = 1;
    RCU->RSTDISAHB_bit.TMR1EN = 1;

    TMR1->CTRL_bit.ENABLE = 0;
    // Период = (100 МГц / F_s) - 1
    TMR1->LOAD = (100000000UL / trigger_freq_hz) - 1;
    TMR1->CTRL_bit.MODE = 1;      // Периодический режим
    TMR1->CTRL_bit.INTEN = 0;     // Прерывание ядра не нужно, таймер дергает АЦП аппаратно
    TMR1->CTRL_bit.ENABLE = 1;
}

/**
 * @brief Инициализация модуля АЦП
 */
void ADC_Sequencer_Init(void)
{
    // 1. Тактирование блока АЦП
    RCU->CGCFGAHB_bit.ADCEN = 1;
    RCU->RSTDISAHB_bit.ADCEN = 1;

    // 2. Делитель частоты тактирования АЦП
    ADC->CLKDIV_bit.DIV = 4; // Тактовая АЦП в допустимом диапазоне

    // 3. Конфигурация секвенсора 0:
    // Источник триггера — событие совпадения таймера TMR1
    ADC->SEQ[0].CTL_bit.TRIG = 2; // 2 = Внутренний триггер от TMR1
    ADC->SEQ[0].CTL_bit.RESTART = 1;

    // Опрос канала CH0, признак конца цепочки на первом шаге
    ADC->SEQ[0].CH[0] = 0;
    ADC->SEQ[0].CTL_bit.LEN = 0;  // Длина цепочки = 1 преобразование

    // 4. Включение запроса DMA от секвенсора АЦП
    ADC->SEQ[0].CTL_bit.DMAEN = 1;

    // 5. Разрешение работы секвенсора и аналоговой части
    ADC->SEQ[0].CTL_bit.EN = 1;
    ADC->CTL_bit.ENABLE = 1;
}

/**
 * @brief Конфигурация канала DMA для работы с АЦП
 */
void DMA_ADC_Channel_Init(void)
{
    // Включение тактирования DMA
    RCU->CGCFGAHB_bit.DMAEN = 1;
    RCU->RSTDISAHB_bit.DMAEN = 1;

    DMA->EN_bit.ENABLE = 1; // Общее включение контроллера

    // Настройка дескриптора передачи:
    // Источник: регистр FIFO данных АЦП (ADC->SEQ[0].DATA)
    // Приемник: массив adc_dma_buffer
    DMA->CH[0].SRC = (uint32_t)&(ADC->SEQ[0].DATA);
    DMA->CH[0].DST = (uint32_t)&adc_dma_buffer[0];
    DMA->CH[0].CTRL_bit.SRCSZ = 1; // Чтение по 16 бит
    DMA->CH[0].CTRL_bit.DSTSZ = 1; // Запись по 16 бит
    DMA->CH[0].CTRL_bit.SRCINC = 3; // Без инкремента источника (чтение из одного регистра)
    DMA->CH[0].CTRL_bit.DSTINC = 1; // Инкремент адреса назначения на 2 байта
    DMA->CH[0].CTRL_bit.CYCLE = 2;  // Режим Ping-Pong / Double-buffer
    DMA->CH[0].CTRL_bit.TOTAL = BUFFER_TOTAL_SIZE - 1;

    // Разрешение прерываний половины передачи и полного цикла
    DMA->CH[0].INTEN_bit.HT = 1;
    DMA->CH[0].INTEN_bit.TC = 1;
    PLIC_EnableIRQ(DMA0_IRQn);

    // Активация канала
    DMA->CH[0].EN_bit.ENABLE = 1;
}

/**
 * @brief Функция скользящего усреднения половины буфера
 */
void Process_Buffer_Block(uint16_t *src_buf, uint16_t length)
{
    for (uint16_t i = 0; i < length; i++) {
        // Перевод кода АЦП в физическое напряжение (0 .. 3.3 В)
        adc_filtered_voltage[i] = ((float)src_buf[i] / 4095.0f) * 3.3f;
    }
}

/**
 * @brief Обработчик прерывания DMA
 */
void DMA0_IRQHandler(void)
{
    if (DMA->CH[0].STATUS_bit.HT) 
    {
        // Заполнена первая половина буфера (Ping: 0 .. BUFFER_HALF_SIZE - 1)
        Process_Buffer_Block(&adc_dma_buffer[0], BUFFER_HALF_SIZE);
        DMA->CH[0].STATUSCLR_bit.HT = 1;
    }

    if (DMA->CH[0].STATUS_bit.TC) 
    {
        // Заполнена вторая половина буфера (Pong: BUFFER_HALF_SIZE .. BUFFER_TOTAL_SIZE - 1)
        Process_Buffer_Block(&adc_dma_buffer[BUFFER_HALF_SIZE], BUFFER_HALF_SIZE);
        DMA->CH[0].STATUSCLR_bit.TC = 1;
    }
}
```
